# colors-lamp
Assignment 1

# Description
This is for the first colors website which allows you to login, add, and search for their colors

# Technologies Used
 - Apache, MySql, PHP (Lamp stack)
 - html, CSS, JavaScript
 - Api design tested with Postman

# Project scructure
api/ - these have the PHP files and are the backend endpoints
public/ - these are the frontend files and are for the UI

# Setup
1. Install a LAMP server
2. Create the MySQL database and tables
3. Copy the api/ and public/ folders from the local into the server files using filezilla

# Running the App
open http://http://cop4331lucasmwebsite.com/ in a browser
